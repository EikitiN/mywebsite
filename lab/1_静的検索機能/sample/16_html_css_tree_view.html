JavaScriptを使わずにHTMLとCSSだけで階層ツリーを作る

サイトのサイトマップやカテゴリ一覧を階層構造（ツリービュー）で表示したい場合、重厚なUIライブラリを導入しなくても、HTML5標準の <details> と <summary> タグを組み合わせるだけで開閉可能なツリーを実装できる。

罫線（ガイドライン）の描画

ネストされた <ul> 要素の左側に border-left を設定し、各 <li> 要素の ::before 疑似要素で横線を引くことで、エクスプローラーのような視覚的な接続線を純粋なCSSのみで表現できる。キーボード操作やスクリーンリーダーにも標準で対応できる点が大きな利点である。
