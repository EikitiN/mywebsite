Pythonのリスト内包表記を理解する

Pythonにはリスト内包表記（list comprehension）という、リストを簡潔に生成する構文がある。慣れると手放せなくなる一方、初見では読みにくいと感じる人も多い。基本形は次のとおりだ。

[式 for 変数 in イテラブル]

たとえば0から9までの2乗のリストを作るなら、for文では空リストにappendを繰り返すが、内包表記なら [x**2 for x in range(10)] の一行で済む。可読性が上がり、実行速度もわずかに有利なことが多い。

条件を付けたい場合は末尾にifを置く。[x for x in range(20) if x % 2 == 0] で偶数だけを抽出できる。ifとelseを両方使う場合は式の側に書く。["偶数" if x % 2 == 0 else "奇数" for x in range(10)] のように、条件分岐の位置が変わる点に注意したい。

入れ子のループも内包表記で書ける。[(i, j) for i in range(3) for j in range(3)] は9組のタプルを生成する。ただし入れ子が深くなると読みにくくなるため、可読性を優先するなら通常のfor文に戻す判断も必要だ。

内包表記はリストだけでなく、辞書（dict comprehension）や集合（set comprehension）、ジェネレータ式でも使える。{k: v for k, v in pairs} のように書けば辞書を生成できる。ジェネレータ式は (x for x in range(10)) と丸括弧で書き、メモリを節約したい場面で役立つ。

注意点として、副作用を目的とした処理を内包表記で書くのは避けたい。あくまで「値を作る」ための構文であり、printやファイル書き込みなどを詰め込むと意図が伝わりにくくなる。簡潔さと読みやすさのバランスを意識して使うのがよい。
