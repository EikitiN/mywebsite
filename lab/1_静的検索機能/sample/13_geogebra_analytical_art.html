円と直線の方程式だけで描く幾何学アートの技法

GeoGebraやDesmosといったグラフ描画ソフトでは、y = f(x) のような陽関数だけでなく、F(x, y) = 0 の形の陰関数や不等式を直接プロットできる。

定義域の制限（クリッピング）

円の方程式 (x - a)² + (y - b)² = r² をそのまま描くと完全な円になるが、中括弧を用いた条件式を付与することで、特定の角度や領域だけの円弧（アーク）を切り出すことができる。

さらに、2つの曲線 f(x, y) = 0 と g(x, y) = 0 の積をとった方程式 f(x, y)・g(x, y) = 0 を記述すると、1本の数式の中に複数のパーツを同時に描画でき、式の管理が劇的にシンプルになる。
