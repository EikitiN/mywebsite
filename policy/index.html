個人情報の取得・取り扱い

当サイトは GitHub Pages を利用してホスティングされています。サイトへのアクセス時に、 セキュリティ維持やサービス向上のため、GitHub のサーバーによって IP アドレス等のアクセスログが自動的に 記録される場合があります。これらのデータの取り扱いについては、 GitHub General Privacy Statementをご確認ください。
なお、当サイトの運営者自身が閲覧者の個人情報を明示なしに能動的に収集・保存することはありません。

お問い合わせで作られたIssueは制限なく全体に公開されます。個人情報を記載しないでください。 バグ修正等の改善のため、お問い合わせに記された情報をIssueで本人様の許可が取れた場合AIで処理する場合があります。 その際、個人情報とみられる情報を発見次第、修正してから処理を行うよう注意しますが、 修正しきれない場合もありますので添付する画像等に個人情報が含まれないかよく確認してください。

お問い合わせ等で個人情報が発見された場合、Issueを削除する措置をとらせていただくことがあります。

お問い合わせ等で収集されたすべての情報をサイト改善以外の目的では使用しません。 また、以下の場合を除き同意なしに第三者に個人情報が送信されることはありません。

Cookieの利用

当サイトでは、アクセス解析などの目的でCookieを使用しています。
Cookieとは、利用者がWebサイトを閲覧した際に、ブラウザに保存される情報です。 Cookieによって、利用者個人を直接特定する情報を取得するものではありません。

利用者は、ブラウザの設定によりCookieを無効にすることができます。 ただし、その場合、Webサイトの一部機能が正常に動作しないことがあります。

Googleアナリティクスの利用について

当サイトでは、サイトの利用状況を把握し、サービスの改善を目的として、 Googleが提供するアクセス解析ツール「Googleアナリティクス」を利用しています。
Googleアナリティクスは、Cookie等を利用して、利用者の閲覧ページ、アクセス日時、 利用環境などの情報を収集・分析します。
これらの情報には、個人を直接特定する情報は含まれません。
