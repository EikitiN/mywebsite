問題・状況

webページ作成中、cssを変更したが、テスト環境において変更が見られない。

テスト環境がスマートフォンで、開発者ツールで確認できない

解決手段

</body>直前に現在読み込んでいるcssを書き出し表示するプログラムを追加する。

体裁はあとで整える

実際にこのページで利用してみている。一番下を参照


    <div id="debug-css-output"></div>
    <script>
        window.addEventListener('load', function() {
        const output = document.getElementById('debug-css-output');
        output.style.whiteSpace = 'pre-wrap';
        output.style.fontFamily = 'monospace';
        output.style.backgroundColor = '#f9f9f9';
        output.style.padding = '15px';
        output.style.borderRadius = '6px';
        output.style.border = '1px solid #ddd';

        let result = '';

        for (let i = 0; i < document.styleSheets.length; i++) {
            const sheet = document.styleSheets[i];
            if (sheet.href && sheet.href.includes('style.css')) {
                result += 'ファイルURL: ' + sheet.href + '\n';
                result += '----------------------------------------\n';
                try {
                    const rules = sheet.cssRules || sheet.rules;
                    for (let j = 0; j < rules.length; j++) {
                        result += '  ' + rules[j].cssText + '\n';
                    }
                } catch (e) {
                    result += 'エラー: ' + e + '\n';
                }
                result += '\n';
            }
        }
        output.textContent = result || 'CSSが見つかりませんでした。';
    });
    </script>
